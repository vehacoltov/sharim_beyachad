# Git Hunk Keep/Undo

הרחבת VS Code להצגת פעולות Keep ו־Undo ליד כל hunk ששונה ביחס ל־`HEAD`.
היא נפרדת מאפליקציית React ומשתמשת ב־Git המקומי בלבד.

## שימוש

1. פתח את הפרויקט ב־VS Code והתקן את Git כך שהפקודה `git` תהיה זמינה ב־PATH.
2. פתח את תיקיית `vscode-keep-undo` בחלון VS Code נפרד.
3. הרץ `npm test` כדי לוודא את פענוח ה־diff.
4. לחץ `F5` כדי לפתוח חלון Extension Development Host.
5. בחלון החדש פתח מאגר Git, ואז פתח קובץ שיש בו שינויים לא־מקובעים.
6. הרחבה תציג שורות שנוספו עם הדגשה ירוקה, ולידן `Keep` ו־`Undo`.

## משמעות הפעולות

- **Keep** משאיר את תוכן הקובץ כפי שהוא ומסמן את ה־hunk כנסקר ב־workspace state.
- **Undo** מחליף רק את שורות ה־hunk שנבחרו בשורות המקוריות מ־`HEAD`.
  השינוי נשאר לא שמור בעורך, כך שאפשר לבדוק אותו לפני שמירת הקובץ.
- הפעולות אינן מבצעות stage או commit. אפשר לרענן את הסקירה דרך
  `Git Hunk Keep/Undo: Refresh Review` מתוך Command Palette.
- אם תוכן ה־hunk השתנה מאז הצגת הפעולות או שהקובץ נערך בזיכרון באזור זה,
  ההרחבה מסרבת לבטל ומבקשת לרענן במקום לדרוס עריכות.

הרחבה זו סוקרת שינויי Git שכבר קיימים בקבצים. היא אינה משחזרת הצעות inline
של Copilot ואינה מוסיפה פקדים לעורך VS Code שמריץ את הפרויקט עצמו.
